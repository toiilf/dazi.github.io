小鹤双拼练习工具

一款纯 HTML 搭建的简易轻量化小鹤双拼在线练习工具，无需复杂环境、无需安装软件，打开浏览器即可使用，支持 PWA 本地安装使用，专为小鹤双拼输入法学习者、练习者打造，覆盖从基础单字到整篇文章的全阶段打字训练，帮助用户快速熟悉小鹤双拼键位，提升打字速度与准确率。

在线访问地址：https://www.beloveys.top


✨ 项目特点

- 极简轻量化：纯前端 HTML 开发，代码简洁、无冗余依赖，加载速度极快
- 零使用门槛：无需部署、无需安装插件，任意浏览器直接运行

- 自定义文章本地存储：支持自主添加练习文章，题库完全自定义，数据本地化保存，隐私性极强，刷新重启不丢失
- 支持 PWA 渐进式网页应用：适配 PWA 标准，可浏览器安装到本地使用，摆脱网页依赖，拥有类原生软件体验，启动更快、使用更便捷

📌 核心功能

工具包含三大核心练习模块，循序渐进适配不同练习阶段的用户：
1. 单字练习
适合新手入门阶段。以单个常用汉字为练习单元，帮助初学者熟悉小鹤双拼基础键位、字根对应关系，摆脱全拼思维，习惯双拼输入逻辑，夯实基础指法，解决键位不熟、拆字卡顿的问题。
2. 词语练习
适合进阶提升阶段。基于日常高频词语进行专项训练，贴合实际打字场景，锻炼双拼组合输入手感，提升词语输入的连贯性和速度，摆脱单字输入的割裂感，逐步适配日常打字节奏。
3. 文章跟打
适合实战提速阶段。支持完整文章全文跟打练习，模拟真实文案输入场景，综合训练打字速度、准确率和手速连贯性，适配日常办公、文案输入等实际使用需求，全方位提升双拼实战能力。同时支持自定义添加文章，用户可自行导入喜欢的文案、素材、读书笔记等内容，个性化定制跟打练习内容，适配个人专属练习场景，练习自由度更高。

💻 使用方法

1. 下载项目所有 HTML 源码文件到本地电脑
2. 无需配置环境、无需编译、无需部署服务
3. 直接双击 html后缀文件，或通过浏览器打开在线地址，即可进入练习界面
4. 根据自身练习需求，选择单字、词语、文章跟打对应模块开始训练
   
📱 PWA 安装使用

本项目完整适配 PWA 渐进式网页应用，支持主流浏览器（Chrome、Edge、360 极速浏览器等）安装至设备本地，实现零浏览器打开、离线使用、秒级启动。
安装方法
- 电脑端：浏览器打开项目页面，地址栏右侧会出现「安装」图标，点击即可一键安装为本地应用
- 手机端：支持安卓/iOS 主流浏览器，可添加到桌面，生成独立应用图标
安装后无需打开浏览器，点击桌面图标即可直接启动练习工具，无地址栏、无浏览器边框，沉浸式练习体验。

📝 项目说明

本项目为个人开源简易练习工具，纯前端原生开发，无后端接口、无数据上传，所有练习操作均在本地浏览器完成，隐私安全无顾虑。
项目主打轻量化、实用性，支持 PWA 安装使用、支持用户自行添加自定义练习文章且数据本地浏览器存储，专注解决小鹤双拼用户的日常练习需求。
